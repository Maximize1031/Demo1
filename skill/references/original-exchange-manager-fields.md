# Exchange Manager Pro — Field Reference

This document maps the exact fields and steps in Accruit's Exchange Manager Pro submission process.
Source: QIConnect Exchange Submissions guide.

## Step 1: Create New Exchange — Entity Selection

Select the entity type that holds title to the property being sold:

| Entity Type | Additional Document Required |
|---|---|
| Individual | None |
| Single Member LLC | Operating Agreement |
| Multi-Member LLC | Operating Agreement |
| Corporation | Corporate Signing Resolution |
| Trust | Trust Documents |
| Partnership | Partnership Agreement |

## Step 2: Titleholder Information

| Taxpayer Name | Yes | Name of Person Filing Tax Return (may differ from titleholder) |
| SSN or EIN | Yes | Tax Identification Number as shown on Tax Return |
| Titleholder Address Line 1 | Yes | |
| Titleholder Address Line 2 | No | |
| City | Yes | |
| State | Yes | |
| Zip Code | Yes | |
| Phone | Yes | |
| Operating Agreement | Conditional | Required for LLC entities |
| W-9 | Conditional | Required if interest is being shared with the taxpayer |

## Step 3: Contacts

| Field | Required | Notes |
|---|---|---|
| Use Titleholder Information? | No | Checkbox to auto-fill from Step 2 |
| First Name | Yes | |
| Last Name | Yes | |
| Email | Yes | |
| Phone | Yes | |

Multiple contacts can be added (e.g., CPA, attorney, broker).

## Step 7: Additional Documents

Upload any additional documents. Types available:
- W-9
- Certificate of Good Standing
- Drivers License
- Trust Documents
- Organizational Documents
- Partnership Agreement
- Intake Form

## Step 8: Exchange Notes

Free-text field for additional information including:
- Exchange fees different than standard
- Back-to-back closings (within 48 hours of one another)
- Seller financing
- Tenants-in-Common ownership
- Rush fees
- Any other special circumstances

## Step 9: Review & Submit

Review screen shows all information provided. Required fields that are missing are highlighted in RED. The exchange cannot be submitted until all required fields are complete, but it can be saved and returned to later.

### Required for Submission Checklist:
- Titleholder Information (all fields)
- Contact (at least one primary contact)
- Relinquished Property(s) (address, closing date, sale contract, title commitment, closing agent)
- Internal Referral (name, email)
